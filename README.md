# Overleaf Resume Guide

A beginner-friendly guide to creating a professional and ATS-friendly resume using **Overleaf and LaTeX**.

## 📌 About This Project

This repository explains how to create a professional resume using Overleaf. It includes the LaTeX source code, a sample resume, and step-by-step instructions.

## 🛠️ Tools Required

- Overleaf – Online LaTeX editor
- GitHub – To store and share the source code
- PDF Reader – To view the generated resume

## 🚀 Steps to Create a Resume

### Step 1: Create an Overleaf Account
Visit https://www.overleaf.com/ and create a free account.

### Step 2: Create a New Project
- Click New Project.
- Select Blank Project.
- Give your project a name.

### Step 3: Add LaTeX Code
- Open the `main.tex` file.
- Paste the resume template code.
- Replace the sample details with your own information.

### Step 4: Compile the Resume
- Click Recompile.
- Check the PDF preview.
- Correct any formatting errors.

### Step 5: Download Your Resume
Download the generated PDF and save it to your computer.
